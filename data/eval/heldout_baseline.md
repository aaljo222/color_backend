# Held-out 검색 일반화 측정 (키워드 변경 전)

- Held-out 문항: A 15, B 8, C 7 (총 30)
- 기존 threshold와 strict 장치 그대로 사용: `TAU=0.12`, 같은 논문 비율 `0.60`, 다른 논문 기준 `0.28` 및 상위 점수 비율 `0.70`, 모호성 차이 `0.01`, 원문 일치 `N=1`
- 문항 라벨은 검색 실행 전에 카드와 `papers_text` 근거로 지정했습니다. 평가는 외부 요청 없이 검색 함수만 호출했습니다.
- 기존 `scripts/eval_chat.py` CLI는 40문항 및 그룹별 최소 10개를 하드코딩해 30문항 held-out를 거부합니다. 코드 변경 금지 조건을 지키기 위해 같은 스크립트의 `evaluate()` 함수를 해당 30문항에 직접 호출했습니다. 기준과 계산은 CLI 평가기와 동일합니다.

## Strict held-out 실패 문항

- A 정답 카드를 채택하지 못함: `H-A03` (예상 `wilms2018_abs`), `H-A04` (`wilms2018_physio`), `H-A12` (`zhu2015_culture`). A 정답 카드 점수 중 최저는 `0.053`으로 `TAU=0.12` 아래입니다.
- C에서 예상 밖 근거 채택: `H-C04` (예상 `wilms2018_physio`, `langlois_poster`; 실제 `news2013_music`), `H-C07` (예상 `ou2004_model3`, `palmer2010_evt`; 실제 `wilms2018_which`).
- B 8문항은 모두 paper 근거로 채택되지 않았습니다. 최고 TF-IDF 점수 `0.110`은 TAU 바로 아래입니다.

## 해석

Strict A@1은 기존보다 5%p, A@2 및 정답 카드 채택은 10%p 낮아졌습니다. 특히 strict C 오답 채택률은 20.0%에서 28.6%로 8.6%p 높아졌고 정밀도도 2.7%p 낮아졌습니다. 따라서 작은 held-out 표본에서도 **일반화 저하 및 문턱값 과적합 가능성 신호**가 관찰됩니다. 그러나 C 표본이 7개뿐이고 B가 8개여서 통계적으로 확정적인 과적합 판정은 어렵습니다.

Held-out A 최저 정답 점수 `0.053`과 B 최고점 `0.110` 사이에 분리 구간이 없습니다. 현재 threshold는 변경하지 않았으며, 이 보고서만으로 재조정하지 않았습니다. 세부 질문과 라벨 검토용 위치는 `review_sheet.md`에 있습니다.
