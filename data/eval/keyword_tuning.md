## 수정 전후 지표

평가셋 순서는 A@1 / A@2 / A 정답 카드 채택 / B 거절 / C 오답 채택 / A+C 정밀도입니다. trial 결과는 키워드 추가 직후, final은 회귀로 인해 추가분을 되돌린 뒤입니다.

| 평가셋 | 모드 | 수정 전 | 키워드 trial | 최종 |
|---|---|---|---|---|
| 기존 40문항 | Legacy | 90.0 / 100.0 / 90.0 / 100 / 50.0 / 66.7% | 90.0 / 100.0 / 90.0 / 100 / 50.0 / 68.2% | 수정 전과 동일 |
| 기존 40문항 | Strict | 85.0 / 90.0 / 90.0 / 100 / 20.0 / 85.3% | 85.0 / 90.0 / 90.0 / 100 / 20.0 / 82.4% | 수정 전과 동일 |
| Held-out 30문항 | Legacy | 86.7 / 86.7 / 80.0 / 100 / 42.9 / 63.6% | 86.7 / 93.3 / 80.0 / 100 / 42.9 / 67.7% | 수정 전과 동일 |
| Held-out 30문항 | Strict | 80.0 / 80.0 / 80.0 / 100 / 28.6 / 82.6% | 80.0 / 80.0 / 80.0 / 100 / 28.6 / 82.6% | 수정 전과 동일 |

정밀도 변화는 기존 평가셋 Strict에서 -2.9%p, held-out Legacy에서 +4.1%p였습니다. 두 평가셋의 일부 지표가 일관되게 개선되지 않았고, 아래 대상 문항 점수도 악화됐으므로 지시대로 trial 키워드를 되돌렸습니다.

키워드 추가만으로 한국어 표현과 논문 개념의 의미 대응을 안정적으로 개선하지 못했고, 카드별 벡터 정규화·순위에도 예상치 못한 영향이 있었습니다. 저장된 `data/chat_kb.json`은 원본 백업 `data/chat_kb.json.stage5-2-before.bak`과 SHA-256이 같으며, 키워드 수정은 남기지 않았습니다.
